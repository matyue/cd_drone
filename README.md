> **Автономный дрон-ретранслятор** для поддержания связи в роевых системах. Проект включает 3 этапа обучения ML-агента, физическую симуляцию полёта и управление через точечные силы моторов.

---


## ✨ Особенности проекта

- 🧠 **3-этапное обучение ML-агента** (от простого к сложному)
- ⚙️ **Физическое управление** через приложение сил в точках моторов
- 🎯 **Удержание цели** в рабочей зоне дрона
- 🔗 **Динамическое соединение целей** для построения сети
- 🏳️ **Флаговая маршрутизация** (сетевая логика заготовлена)
- 🌀 **Реализовано вращение** вокруг оси (yaw) + стабильное зависание

---

## 🧠 Архитектура обучения

Обучение агента проходило в **3 этапа**, каждый из которых добавлял новый уровень сложности.

| Этап | Цель | Статус |
|------|------|--------|
| **Этап 1** | Удержание цели в заданном радиусе от дрона | ✅ Завершён |
| **Этап 2** | Соединение двух целей (обеспечение линии связи) | ✅ Завершён |
| **Этап 3** | Соединение целей с учётом флагов сети (маршрутизация) | ⚠️ Окружение подготовлено, обучение не проведено |

> 💡 *«Окружение для этапа 3 не до конца готово.»*

---

## 🎮 Управление дроном

Дрон управляется в **физической симуляции** с применением реалистичных сил:

    A[Точки приложения сил] --> B[4 мотора (квадрокоптер)];
    B --> C[Суммарный вектор тяги];
    C --> D[Перемещение + Вращение];
    D --> E[Зависание];
    D --> F[Вращение вокруг оси Yaw];
